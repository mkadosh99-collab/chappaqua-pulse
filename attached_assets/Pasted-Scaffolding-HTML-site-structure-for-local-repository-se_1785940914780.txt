Why CLAUDE.md matters more than the HTML here. Claude Code starts every session cold. Without it, the first thing it'll do is see 749 lines of hand-written CSS and SVG and "helpfully" refactor it into React, swap Outfit for Inter, and drop a stock-photo hero on top — because those are the defaults. The file locks in the things that are actually decisions:

Exact hex tokens, with a note that category colors are load-bearing — they match the printed brochure legend 1:1, so a resident can hold the paper map next to their phone and see the same colors. That's a constraint no one would infer from the code.
The four choices worth defending (no photo hero, one event module not two, --field orange reserved for the map, script face used sparingly) written down as choices, with reasons.
A hard warning that the business listings are invented. That's the highest-risk item in the repo — an agent left alone with a half-empty directory will cheerfully generate forty more fake Chappaqua restaurants, and some of them will sound real enough to publish.
A prioritized next-up list, so claude has somewhere to start other than "improve the code."
